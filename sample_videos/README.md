# Demo video sources

- **real_baseline.mp4** and **real_cut.mp4** are adaptations of a HumynLabs Street-videos clip, distributed here under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). The reference was resized, shortened and re-encoded without audio. The edit additionally removes the interval 2.000–3.000 s in reference time. The camera label follows the source metadata. [HumynLabs dataset card](https://huggingface.co/datasets/HumynLabs/Street-videos) · [Original clip](https://huggingface.co/datasets/HumynLabs/Street-videos/resolve/main/2b7670d3-0a81-4143-8dcf-b03ed1f592f3.mp4_2b7670d3-0a81-4143-8dcf-b03ed1f592f3.mp4)
- **veo3.1.mp4** is Rapidata’s `veo31_03_0.mp4`, renamed for the demo and byte-identical to the downloaded clip. The publisher lists [Apache 2.0](https://www.apache.org/licenses/LICENSE-2.0) and identifies Veo 3.1 as its generator. [Rapidata dataset card](https://huggingface.co/datasets/Rapidata/text-2-video-human-preferences-veo3.1) · [Original clip](https://huggingface.co/datasets/Rapidata/text-2-video-human-preferences-veo3.1/resolve/main/videos/veo31_03_0.mp4)
